# Sriya Mukkawar — Portfolio

Personal portfolio mixing the colorful fluid-cursor theme of [aaabadcode.com](https://www.aaabadcode.com/) with the section flow and mouse-following character of [redoyanulhaque.me](https://www.redoyanulhaque.me/).

Built with **React (Vite)** and a small **Node/Express** API.

## Run locally

```bash
npm install
npm run install:all
npm run dev
```

- Frontend: http://localhost:5173
- API: http://localhost:5001

## Customize

Edit `client/src/data/content.js` for your name, projects, experience, and links.

The contact form posts to `POST /api/contact` on the Node server.
